1. Preserve current main recovery behavior; work only on the feature branch. Audit staging's actual contracts and capture baseline results.
2. Add an atomic owner/guest-proof cancellation RPC with order/suborder locks and paid/processing/legacy guards. Serialize initiation through the existing server-only prepare RPC. Keep return navigation non-mutating. Do not infer provider cancellation from a browser redirect.
3. Validate new mobile inputs client/server; retain exact legacy guest proof and unchanged stored vendor contacts. Registration, customer profile and vendor application currently have no phone input/storage contract; do not invent user metadata phone fields. Existing actual fields are checkout guest mobile, Track Order proof and vendor settings contact. Explicit international mode is available for vendor contact editing.
4. Add accurate/stale-request-safe browser geolocation, disabled-by-default delivery policy, short-lived owner/guest/cart-bound quotes and server-authoritative fee totals. Preserve legacy checkout while policy is disabled; reject quote-less checkout once enabled. Keep delivery revenue separate from vendor meal commission and order/payment reconciliation.
5. Provide admin-only audited gateway/delivery controls. Preserve PayFast; Ozow remains unavailable and cannot be enabled through admin settings until server readiness is separately established. Webhook verification is independent of initiation enablement.
6. Prepare documented Ozow One API token/request/Svix verification helpers without wiring or deploying them to transact. Merchant onboarding and an atomic provider-neutral confirmation/idempotency ledger must precede activation. Never route Ozow into PayFast-specific confirmation/log tables.
7. Prepare paid subscription design and eligibility tests. Preserve existing marketplace/growth pricing, tier overrides and commission rules; no new price/benefit/renewal/refund policy is guessed. No entitlement activation endpoint is shipped until verified provider settlement and the paid-plan catalog are specified.
8. Run isolated SQL, unit/contract, browser fixture, build, lint and Deno checks; apply only reviewed migration to staging if native prerequisites still match. Report hosted/native versus mocked evidence separately. Make incremental local commits; do not push main, deploy production or transact.
